# Robot Tea

Голосовой помощник для Windows. Первая версия умеет распознавать русские голосовые команды, отвечать голосом и запускать несколько приложений.

## Сборка через GitHub

1. Открой вкладку **Actions** в репозитории.
2. Выбери **Build Robot Tea**.
3. Нажми **Run workflow** и подтверди запуск.
4. После успешной сборки открой запуск workflow и скачай артефакт **RobotTea-Windows**.
5. Распакуй архив и запусти `RobotTea.exe`.

Сборка автоматически запускается и при изменении основных файлов в ветке `main`.

## Возможности первой версии

- Русское распознавание речи через онлайн-сервис Google Speech Recognition.
- Голосовые ответы через системный синтез речи Windows.
- Запуск Steam, Minecraft Launcher, Блокнота, Калькулятора, браузера и Проводника.
- Поиск файлов в основных пользовательских папках (Загрузки, Рабочий стол, Документы, Изображения и др.).
- Создание папок в Документах или на Рабочем столе без разрешения на произвольные пути.
- Снимок экрана с сохранением локально в Изображения/RobotTea-Screenshots.
- Отчёт о Windows, оперативной памяти, свободном месте на диске и батарее (если она есть).
- Тёмный интерфейс и журнал команд.
- Диалог с OpenAI API через текст или распознанную голосовую речь.
- Ключ API хранится в хранилище учётных данных Windows, не в исходном коде.

## Важно

- Для распознавания речи нужен интернет и доступ к микрофону.
- Разрешения микрофона и звук проверяются на компьютере, где запускается приложение.
- Команды поиска файлов, создания папок, скриншотов и сведений о системе работают локально; скриншоты никуда не отправляются.
- Поиск ограничен основными пользовательскими папками и пропускает системные/служебные каталоги.
- Robot Tea не удаляет файлы и не запускает произвольные команды PowerShell по голосу.
- Не выполняйте через голосовые команды удаление файлов, покупки или другие важные действия без подтверждения.

## Подключение ИИ

1. Скачай и запусти приложение на своём Windows-компьютере.
2. Нажми **Настроить ИИ** и вставь личный API-ключ OpenAI.
3. Ключ хранится в хранилище учётных данных Windows и не добавляется в GitHub или EXE.
4. Введи сообщение в нижнее поле или нажми **Слушать** и задай вопрос голосом.

API OpenAI оплачивается отдельно от подписки ChatGPT. Создавай ключ только на официальной платформе OpenAI, не присылай его в чат и не публикуй в репозитории. Если ключ когда-либо попал в публичный доступ, отзови его и создай новый.

ИИ отвечает на вопросы; запуск приложений выполняется только для команд, которые уже реализованы в программе. Произвольное управление компьютером и подтверждение действий — отдельные будущие функции.
